===========================
Basic OpenCV-Nodes for ABMT
===========================

Content
=======
 - calib_rec.acfg: Record a calibration stream. Click use_image in the calib-view to select an image you want to use for calibration.
 - calib_play.acfg: Playback the recorded stream and create camera calibration files.
 - undistort.acfg: Displays the undistorted camera image.
 - marker.acfg: Arcu-Marker display. Prints the distance to the detected marker to the console.
